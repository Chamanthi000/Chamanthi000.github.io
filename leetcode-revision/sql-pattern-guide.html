01Window rankingRank people, products, or scores inside each group.⌄
MENTAL MODELWINDOW ranks rows without collapsing them.
SQL STARTER Cover the code, then try writing it yourself
SELECT team, person, score,
       RANK() OVER (
         PARTITION BY team
         ORDER BY score DESC
       ) AS pos
FROM scores;
WATCH OUTRANK skips numbers after ties; DENSE_RANK does not.
RECALLWhich rank keeps equal scores tied?
02Top N by groupFind the best 3 or newest 5 within EACH group.⌄
MENTAL MODELPARTITION resets the ranking for every group.
SQL STARTER Cover the code, then try writing it yourself
WITH ranked AS (
 SELECT team, person, score,
  ROW_NUMBER() OVER (
   PARTITION BY team ORDER BY score DESC
  ) AS rn FROM scores
) SELECT * FROM ranked WHERE rn <= 3;
WATCH OUTUse DENSE_RANK to include all ties at the cutoff.
RECALLWhy not use LIMIT 3 for top 3 per team?
03Running totalsShow the total SO FAR for every date or transaction.⌄
MENTAL MODELSUM OVER + ORDER BY = rolling accumulation.
SQL STARTER Cover the code, then try writing it yourself
SELECT user_id, sold_at, amount,
 SUM(amount) OVER (
  PARTITION BY user_id
  ORDER BY sold_at, sale_id
  ROWS BETWEEN UNBOUNDED PRECEDING
  AND CURRENT ROW) AS running_total
FROM sales;
WATCH OUTChoose a stable order and explicit ROWS frame.
RECALLWhat changes with PARTITION BY user_id?
04Previous / nextCompare an event with the event immediately before or after.⌄
MENTAL MODELLAG looks BACK; LEAD looks AHEAD.
SQL STARTER Cover the code, then try writing it yourself
SELECT user_id, event_date, value,
 LAG(value) OVER (
  PARTITION BY user_id
  ORDER BY event_date
 ) AS previous_value
FROM events;
WATCH OUTSort deterministically; first row has no prior row.
RECALLWhich function compares today with yesterday?
05Self joinsOne row refers to another row in the SAME table.⌄
MENTAL MODELOne table, two roles, two aliases.
SQL STARTER Cover the code, then try writing it yourself
SELECT e.name AS employee,
       m.name AS manager
FROM employees e
LEFT JOIN employees m
 ON e.manager_id = m.id;
WATCH OUTLEFT JOIN retains workers without a manager.
RECALLWhy alias employees twice?
06Anti-joinsFind customers with NO orders or items with NO matches.⌄
MENTAL MODELNOT EXISTS means prove the match is absent.
SQL STARTER Cover the code, then try writing it yourself
SELECT c.customer_id
FROM customers c
WHERE NOT EXISTS (
 SELECT 1 FROM orders o
 WHERE o.customer_id = c.customer_id
);
WATCH OUTNOT IN is unsafe if its subquery returns NULL.
RECALLWhich clause finds customers who never ordered?
07Grouped aggregatesOne answer per city, department, or product category.⌄
MENTAL MODELGROUP BY changes the GRAIN of the output.
SQL STARTER Cover the code, then try writing it yourself
SELECT region, COUNT(*) AS n_orders,
       SUM(amount) AS revenue
FROM sales
WHERE amount > 0
GROUP BY region
HAVING COUNT(*) >= 3;
WATCH OUTWHERE filters rows; HAVING filters groups.
RECALLWhere do you filter groups with 3+ orders?
08Conditional pivotsShow categories side by side as separate output columns.⌄
MENTAL MODELCASE chooses a bucket; SUM adds that bucket.
SQL STARTER Cover the code, then try writing it yourself
SELECT region,
 SUM(CASE WHEN kind = 'A'
     THEN amount ELSE 0 END) AS a_sales,
 SUM(CASE WHEN kind = 'B'
     THEN amount ELSE 0 END) AS b_sales
FROM sales GROUP BY region;
WATCH OUTCheck NULLs, the ELSE branch, and row grain.
RECALLWhat creates separate A and B columns?
09DeduplicationKeep the latest or preferred row for each ID.⌄
MENTAL MODELRank within each ID, then KEEP row one.
SQL STARTER Cover the code, then try writing it yourself
WITH ranked AS (
 SELECT t.*, ROW_NUMBER() OVER (
  PARTITION BY user_id
  ORDER BY updated_at DESC, id DESC
 ) AS rn FROM records t
) SELECT * FROM ranked WHERE rn = 1;
WATCH OUTAdd a tie-breaker: updated_at may not be unique.
RECALLWhy is DISTINCT alone insufficient?
10CTE pipelinesTurn a messy problem into named, smaller query steps.⌄
MENTAL MODELWITH is a notebook of intermediate answers.
SQL STARTER Cover the code, then try writing it yourself
WITH daily AS (
 SELECT sale_date, SUM(amount) AS revenue
 FROM sales GROUP BY sale_date
)
SELECT sale_date, revenue
FROM daily WHERE revenue > 1000;
WATCH OUTCTEs improve readability, not always runtime.
RECALLWhen are multiple named CTE steps useful?
11Correlated subqueriesFor each outer row, test a related condition.⌄
MENTAL MODELThe inner query refers BACK to an outer row.
SQL STARTER Cover the code, then try writing it yourself
SELECT c.customer_id
FROM customers c
WHERE EXISTS (
 SELECT 1 FROM orders o
 WHERE o.customer_id = c.customer_id
   AND o.amount > 100
);
WATCH OUTEXISTS checks existence; inspect plan for speed.
RECALLWhich outer alias does the inner query use?
12Gaps and islandsFind streaks of consecutive dates, IDs, or numbers.⌄
MENTAL MODELFor consecutive ints: value minus row_num = island.
SQL STARTER Cover the code, then try writing it yourself
WITH x AS (
 SELECT value,
  value - ROW_NUMBER() OVER (
   ORDER BY value) AS island_key
 FROM (SELECT DISTINCT value FROM nums) d
) SELECT MIN(value), MAX(value)
  FROM x GROUP BY island_key;
WATCH OUTDeduplicate first; date math varies by SQL dialect.
RECALLWhy does the subtraction find a streak?
13Date cohortsGroup users by first activity; follow later behavior.⌄
MENTAL MODELFIRST event = cohort; LATER event = activity.
SQL STARTER Cover the code, then try writing it yourself
WITH firsts AS (
 SELECT user_id,
  DATE_TRUNC('month', MIN(event_ts)) AS cohort
 FROM events GROUP BY user_id
) SELECT cohort, COUNT(*) AS users
FROM firsts GROUP BY cohort;
WATCH OUTThis query counts cohort sizes, not retention.
RECALLWhat determines a user's cohort?
14Recursive queriesWalk an org chart or parent-child hierarchy.⌄
MENTAL MODELANCHOR starts; RECURSION follows; STOP guards.
SQL STARTER Cover the code, then try writing it yourself
WITH RECURSIVE org AS (
 SELECT id, manager_id, 0 AS depth
 FROM employees WHERE id=1
 UNION ALL
 SELECT e.id, e.manager_id, o.depth + 1
 FROM employees e JOIN org o
   ON e.manager_id=o.id WHERE o.depth<10
) SELECT * FROM org;
WATCH OUTDepth limits help; visited IDs also prevent cycles.
