# Shared DSA quality infrastructure

Canonical generation still reads all eleven topics from `data/dsa/`, ending in Union Find. Supplemental alignment, public HTTPS source checks, decision steps and real pattern-to-template links remain validated. The richer renderer retains eight sections, active recall, operation examples, copy controls and neutral Space labels.

The builder now rejects comment-only/blank Python, AST Ellipsis stubs and explicit `raise NotImplementedError` stubs. Strings, comments, `pass`, exception handlers, and legitimate Ellipsis indexing/type parameters remain valid. Template titles require letters, reject placeholder-only labels and are unique after case/whitespace normalization.

Temporary write/replacement failures preserve the previous bundle and remove temporary files. Build tests cover deterministic output, stale checks without writes, malformed present files and safe escaping. Canonical static checks cover all eleven topics; fallback rows are compared directly with their canonical counterparts without evaluating JavaScript.

The canonical runner retains all upstream behavioral cases, adds eleven audit regression suites and requires actual public algorithm/method calls. A negative test confirms that compiling a namespace or calling only one of two functions cannot satisfy the guard. This is invocation coverage paired with assertions and independent oracles, not a mathematical proof or branch-coverage claim.

See [quality-reconciliation.md](quality-reconciliation.md) for measured counts, commands, results and boundaries.
